## ✨ Overview
The **Inventory System** was developed using PHP and MySQL.  
It is a simple yet effective application built with HTML, CSS, JavaScript, Bootstrap, and AJAX.  
This system focuses on **device pull‑out requests for installation purposes** and monitors stock quantities with a user‑friendly interface.

---

## ⚙️ How It Works
All operations are powered by **[CRUD Functions](ca://s?q=Explain_CRUD_Functions_in_Inventory_System)**, allowing administrators to create, read, update, and delete records efficiently.

---

## 🚀 Key Features
- **[Dashboard](ca://s?q=Explain_Dashboard_in_Inventory_System)** – overview of inventory status.  
- **[CRUD Units](ca://s?q=Explain_CRUD_Units_in_Inventory_System)** – manage unit records.  
- **[CRUD Devices](ca://s?q=Explain_CRUD_Devices_in_Inventory_System)** – track devices in stock.  
- **[CRUD Category](ca://s?q=Explain_CRUD_Category_in_Inventory_System)** – organize items by category.  
- **[CRUD Installations](ca://s?q=Explain_CRUD_Installations_in_Inventory_System)** – manage installation requests.  
- **[CRUD System Users](ca://s?q=Explain_CRUD_System_Users_in_Inventory_System)** – handle user accounts and roles.  
- **[Backup/Restore](ca://s?q=Explain_Backup_Restore_in_Inventory_System)** – execute database backup and restore.  
- **[Rollout Reports](ca://s?q=Explain_Rollout_Reports_in_Inventory_System)** – generate summary reports with TCPDF.

## 👩‍💼 Management Features

### General
- All operations use CRUD functions.  
- Only **admin users** are allowed access.  

### Public/User Facing
- Not available (restricted to admins only).  

### Admin Facing
- Dashboard overview.  
- CRUD operations for Units, Devices, Categories, Installations, and Users.  
- Backup and restore database.  
- Generate rollout summary reports.
